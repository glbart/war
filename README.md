# Ядерная стратегия

Браузерная стратегия про **ядерное нераспространение** на настоящей Земле. Вы берёте ядерную
державу и десять минут удерживаете мир от расползания бомбы: договоры, санкции, инспекции,
резолюции ООН, гарантии безопасности, разведка и саботаж. Ядерный удар доступен всегда — и
почти всегда это проигрышный ход.

Страны-претенденты ведут программы сами и тратят на них деньги; ядерные державы принимают
решения через Utility AI и могут спонсировать чужие программы. Каждое решение ИИ объяснимо:
клик по стороне показывает, из чего оно сложилось.

Мир смотрится на **3D-глобусе** (эффекты, удары, разрушаемая воксельная кора) или на **плоской
политической карте** с реальными границами (клавиша `M`).

## Запуск

```
npm install
npm run dev
```

Проверки: `npm test`, `npm run build`, `npm run lint`. Баланс — `npm run balance`
(бездействие обязано проигрывать). Headless-приёмка рендера — `npm run accept`.

## Откуда это выросло

Проект начинался как визуализация-песочница «ядерные удары по 3D-Земле» — она осталась жить
отдельно в [glbart/war](https://github.com/glbart/war). Вся история этой работы сохранена
здесь: коммиты до августа 2026 — общие для обоих репозиториев.

## Документация

`src/sim/countries.data.ts`. Тайлы снимков и подписей на глобусе — Esri.
