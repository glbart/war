# Ядерная песочница

3D-Земля в браузере, по которой можно бить ядерными зарядами и смотреть, что из этого выйдет.
Это **визуализация-песочница**, а не игра: ни целей, ни счёта, ни противника — только планета
и последствия.

Что здесь есть:

- вращаемый глобус со спутниковыми тайлами, границами и названиями (Esri), атмосферой;
- удар кликом по любой точке с выбором мощности (1 / 10 / 100 Мт): вспышка, огненный шар,
  ударная волна, дым, тряска камеры, звук;
- ~266 городов с населением и счётом жертв по ударной волне;
- **реальная разрушаемость**: воксельная кора выгрызается кратерами, поле урона красит гарь и
  полынью, море заливает пробитый берег, обломки-глыбы разлетаются по орбитам;
- трещины и целостность коры, а на нуле — **раскол планеты**: агония, разрыв на куски-плиты,
  распад раскалённого ядра, пустота;
- баллистические МБР: залп по кнопке летит по дуге из точек суши по живым городам.

## Запуск

```
npm install
npm run dev
```

Проверки: `npm test`, `npm run build`, `npm run lint`. Headless-приёмка рендера (ловит ошибки
компиляции TSL, которых не видят сборка и юниты) — `npm run accept`.

## Игра переехала

Поверх этой песочницы выросла отдельная **стратегия про ядерное нераспространение** — с
Utility AI, дипломатией, экономикой, ООН и целью партии. Она живёт в
[glbart/nuclear-strategy](https://github.com/glbart/nuclear-strategy) и развивается сама по
себе: изменения между репозиториями не переносятся. Общая история коммитов до 2026-08-30 есть
в обоих. Здесь же всё намеренно остаётся песочницей — красивой и бесцельной.

## Стек

Vite + TypeScript, `three/webgpu` с автооткатом на WebGL2, все эффекты на TSL, ECS (miniplex)
для эфемерных сущностей, фиксированный тик 30 Гц. Симуляция не знает ни о рендере, ни о вводе.

## Данные

Спутниковые тайлы и подписи — Esri. Маска суши запечена из NASA Blue Marble.
