## Кратко о проекте

Браузерная **стратегия про ядерное нераспространение** на настоящей Земле. Игрок берёт ядерную
державу и десять минут удерживает мир от расползания бомбы: договоры, санкции, инспекции,
резолюции ООН, гарантии безопасности, разведка и саботаж — а ядерный удар остаётся последним
доводом. Страны-претенденты сами ведут программы, тратя на них деньги; ядерные державы
принимают решения через Utility AI и могут спонсировать чужие программы.

Два вида: **3D-глобус** (эффекты, удары, разрушаемая воксельная кора) и **плоская политическая
карта** с реальными границами (клавиша `M`) — для долгой партии.

Конечная цель — многопользовательская онлайн-стратегия; архитектура (шов
`Command → Simulation → Events`) закладывалась под это с самого начала.

## Рабочий цикл

Крупные фичи делаются по схеме: **спека → план → реализация с тестами → приёмка → банк памяти**.
Спеки и планы лежат в `docs/superpowers/{specs,plans}/`.

Проверки перед коммитом: `npm test`, `npm run build`, `npm run lint`.
Баланс игры проверяется массовыми прогонами: `npm run balance`.
