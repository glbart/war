# Страны и фракции — дизайн

_Дата: 2026-08-29. Фичу выбрал пользователь из бэклога; детали решены автономно по мандату._

## 1. Проблема и цель

Сейчас города — безличная россыпь: залп бьёт по «случайным живым городам», гибель Москвы и
гибель Веллингтона одинаково ничего не значат. Нет субъектов, а значит нет ни ответного удара,
ни целей, ни мультиплеера — всё это упирается в отсутствующее понятие «сторона».

Цель этапа: **у городов появляется принадлежность, у сторон — территория, население и
арсенал**. Залп перестаёт быть безадресным: конкретная страна бьёт конкретной страной по
конкретной стране, тратя свои боеголовки. Это фундамент под дипломатию/эскалацию, цели/миссии
и сетевой слой (следующие пункты бэклога).

## 2. Модель

- **Фракция** — игровая сторона: `id`, русское название, цвет, стартовый арсенал (число
  боеголовок), список городов. Восемь ядерных сторон: `usa`, `russia`, `china`, `europe`
  (Великобритания + Франция + союзники), `india`, `pakistan`, `dprk`, `israel`. Плюс
  псевдо-фракция `neutral` — все остальные города (арсенала нет, только гибнет).
- **Принадлежность города** — явный список имён на фракцию (`FACTION_CITIES`), сверяется
  тестом с `CITY_DATA` (опечатка в имени = падающий тест). Город без списка — `neutral`.
  `City` получает поле `faction: FactionId` (не nullable — `neutral` полноценный id).
- **Арсенал** живёт в симуляции (`Map<FactionId, number>`), тратится по одной боеголовке
  на ракету залпа, восстанавливается на `reset`.
- **Пусковые площадки** — территория страны: точка старта берётся у случайного ЖИВОГО города
  агрессора с угловым джиттером `FACTION_LAUNCH_JITTER` (≈3°, rejection-сэмплинг по суше,
  фолбэк — случайная точка суши). Нет живых городов → страна не может пускать, даже с
  арсеналом (обезглавлена) — отдельный флаг не нужен, это следствие.
- **Сторона не «умирает» отдельным состоянием**: HUD сам считает её павшей, когда живого
  населения < 1% от исходного. Симуляция отдаёт только числа.

## 3. Команды и события

- `{ kind: 'salvo', from?: FactionId, to?: FactionId }` — оба поля необязательны:
  не задано → симуляция выбирает через `Rng`. Агрессор: случайная сторона, у которой есть
  арсенал И живые города. Цель: заданная сторона, иначе случайная ДРУГАЯ сторона с живыми
  городами; если таких нет — любые живые города (включая нейтральные); если и их нет —
  прежний фолбэк на случайные точки суши. Ракет в залпе: `min(SALVO_COUNT, арсенал)`.
  Пускать некому → команда молча ничего не делает (HUD гасит кнопку по арсеналу).
- `missileLaunched` дополняется `faction?: FactionId` (чья ракета) — рендер красит след
  цветом стороны; у «удара из космоса» поля нет (прежний цвет выхлопа).
- `cityHit` дополняется `faction: FactionId` и `alive: number` (осталось населения, млн) —
  лента пишет «☠ Москва (Россия)», маркеры городов гаснут по доле выживших.
- Новое `factionsChanged: { factions: { id, popAlive, citiesAlive, arsenal }[] }` — эмитится
  вместе со `statsChanged` (после каждого взрыва), после залпа (арсенал) и на `reset`.
  Статика (название/цвет/исходное население) в событие не кладётся — HUD берёт её из
  `sim/factions.ts` напрямую, как из ассета.

## 4. Рендер

- **`render/CityMarkersView.ts`** — один `InstancedMesh` (октаэдр ~0.006 радиуса) на все
  города: позиция `dir·1.004`, цвет = цвет фракции (нейтральные — серые), масштаб от
  населения (`MARKER_SIZE_MIN..MAX` по `pop`). Живучесть города масштабирует и гасит инстанс:
  `alive/pop` → размер ×(0.35+0.65·f) и цвет ×(0.2+0.8·f), полностью мёртвый город — тёмная
  точка. Источник списка — тот же чистый `createCities()` (детерминированные данные, как
  `landmask`/`ballistics`, общие для sim и рендера); живучесть обновляется по `cityHit`,
  восстанавливается по `planetReset`, весь меш прячется при расколе планеты.
- **`MissileView`**: у следа появляется пер-слотовый юниформ цвета (`uColor`), на `spawn`
  ставится цвет фракции (нет фракции — `TRAIL_COLOR`). Материал следа и так создаётся на слот,
  так что это ещё один юниформ, без новых аллокаций в кадре.

## 5. HUD

- Новая панель **«Стороны»**: строка на фракцию — цветная точка, название, живое население
  (`fmtPeople`), арсенал `☢ N`. Павшая сторона (<1% населения) — приглушена и с «☠».
  Нейтральные — отдельной строкой без арсенала.
- Над кнопкой залпа два `<select>`: **кто бьёт** и **по кому** (первый пункт — «случайно»).
  Кнопка «☢ Залп МБР» шлёт `{kind:'salvo', from, to}`; кнопка блокируется, когда у выбранного
  агрессора нет арсенала или живых городов (при «случайно» — когда пускать некому вообще).
- Лента поражённых городов показывает сторону: `☠ Москва (Россия) — 5,4 млн`.

## 6. Тестирование

- **Юнит `factions`**: каждое имя из `FACTION_CITIES` существует в городах; списки не
  пересекаются; у каждой стороны положительный арсенал и ≥1 город; `factionOfCity` даёт
  `neutral` для города вне списков; агрегаты населения совпадают с суммой по городам.
- **Юнит `salvo`**: залп `from`/`to` стартует из городов агрессора (суша) и бьёт по городам
  цели; тратит арсенал (`min(SALVO_COUNT, arsenal)` пусков, второй залп меньше); при нулевом
  арсенале — ни одного пуска; агрессор без живых городов не выбирается; детерминизм от seed;
  `reset` возвращает арсеналы.
- **Юнит `simulation`**: `cityHit` несёт faction/alive; `factionsChanged` приходит после
  взрыва и на reset; население фракции падает после удара по её городу.
- **Визуал — юзер**: цветные точки городов по сторонам, гаснут при ударе; след залпа окрашен
  в цвет агрессора; панель сторон считает население и арсенал.
- Прогоны: `npm test`, `npm run build`, `npm run lint`.

## 7. Конфиг

`FACTION_LAUNCH_JITTER = 0.05` (рад, разброс пусковых от города); `MARKER_R = 1.004`,
`MARKER_SIZE_MIN = 0.004`, `MARKER_SIZE_MAX = 0.011`, `MARKER_POP_REF = 20` (млн — население
«крупного» города для шкалы размера). Арсеналы и цвета — данные фракций в `sim/factions.ts`,
не в config (это ассет стороны, а не тюнинг эффекта).

## 8. Что НЕ входит (следующие шаги)

Ответный удар и эскалация (фракция сама решает бить), союзы, захват территории, окраска суши
по принадлежности (нужна геометрия границ — сейчас границы даёт тайловый слой Esri), ИИ-цели
и экран итогов. Всё это опирается на введённую здесь модель.

## 9. Риски

- **Политическая рамка.** Стороны — реальные ядерные державы (это уже игра про удары по
  реальным городам). Спорные принадлежности (Тайвань, Киев, Минск, Иерусалим-как-столица)
  не разруливаем: Тайбэй, Киев, Минск, Белград — нейтральные; Израилю отданы Тель-Авив
  и Иерусалим как города из списка, без утверждений о статусе.
- Мелкие стороны (КНДР — один город) гибнут с одного удара и теряют арсенал — так задумано.
- `CityMarkersView` — 266 инстансов, ноль работы на кадр (обновление только по событию).
