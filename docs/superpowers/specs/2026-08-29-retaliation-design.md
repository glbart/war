# Дипломатия и ответный удар — дизайн

_Дата: 2026-08-29. Полный мандат пользователя: решения по видению фичи приняты автономно._

## 1. Проблема и цель

После введения сторон (спека 2026-08-29-factions-design.md) у стран есть население и арсеналы,
но они **пассивны**: бьёт только игрок, в ответ не происходит ничего. Мир не живёт.

Цель: **стороны отвечают сами**. Удар по городам страны запускает ответный залп по агрессору;
союзники вступаются; ответ провоцирует ответ — обмен раскручивается сам и затухает, только
когда кончаются боеголовки или пусковые площадки. Игрок из «бога с кликом» становится
участником: его удары приписываются выбранной стороне, и отвечают ему.

## 2. Модель

- **Атрибуция.** `Warhead` получает `faction?` (чья боеголовка). Жертва удара — сторона,
  потерявшая больше всех населения в этом взрыве (по `hits` из CasualtySystem). Удар без
  жертв (океан, пустыня) никого не провоцирует: территория без городов не моделируется.
- **Аноним.** Ручной клик игрока приписывается стороне, выбранной в HUD («кто бьёт»); при
  «случайно» удар анонимен, и жертва **винит случайную другую воюющую сторону** (Rng) —
  песочница остаётся живой: ткнул в Москву, а мир поехал.
- **Обида (grievance).** Удары накапливаются: пока идёт реакция, новые попадания добавляют
  погибших к уже запланированному ответу и не плодят отдельных волн (залп из 6 ракет = один
  ответ, а не шесть).
- **Реакция — с задержкой** `RETALIATION_DELAY_MIN..MAX` (3–6 с, Rng): волны читаются глазом,
  а не сливаются в кашу.
- **Союзники** (`FACTION_ALLIES`, игровые блоки, не политическое утверждение): удар по стороне
  втягивает её блок — союзник отвечает вполовину меньшим залпом и с добавочной задержкой
  `ALLY_DELAY_EXTRA_*`.
- **Доктрина** — глобальный режим ответа (селект в HUD, команда `setDoctrine`):
  `off` (ответов нет — прежняя песочница), `restrained` (соразмерно: боеголовка на
  `RETALIATION_PER_DEATHS` млн погибших, кап `SALVO_COUNT`), `escalate` (вдвое, кап
  `RETALIATION_CAP_ESCALATE`), `doomsday` (весь арсенал волной, тот же кап — мир кончается
  за пару обменов). По умолчанию — `restrained`.
- **Война.** Первая же атрибутированная пара «жертва ↔ обвиняемый» помечается воюющей
  (симметрично); статус виден в HUD и живёт до `reset`. Отдельной шкалы отношений нет:
  для игры хватает бинарного «мир / война с N сторонами».
- **Кто не отвечает:** нейтральные (нет арсенала), сторона без живых городов (нет пусковых),
  сторона без боеголовок, и никто не отвечает сам себе (жертва == обвиняемый).

## 3. Контракты

- `Command`: `detonate` + `faction?` (чей удар — сторона игрока); новая `setDoctrine`.
- `SimEvent`: новое `retaliationLaunched { from, to, count, reason: 'revenge' | 'ally' }`
  (лента HUD) и `doctrineChanged { doctrine }` (UI отражает состояние sim, как labelsToggled).
  `FactionStat` дополняется `enemies: FactionId[]` — с кем сторона в войне.
- Чистый модуль `sim/diplomacy.ts`: `Doctrine`, `FACTION_ALLIES`, `alliesOf`, `responseSize`
  (обида + арсенал + доктрина + признак союзника → число ракет) — под vitest.

## 4. Как это играется

1. Игрок выбирает свою сторону (селект «кто бьёт») и бьёт по чужому городу.
2. Через 3–6 с жертва отвечает залпом по нему; в ленте — «☢ Россия → США: 3 ракеты».
3. Через ещё пару секунд вступают союзники обеих сторон — обмен расходится по блокам.
4. Каждая волна тратит арсеналы; когда у сторон кончаются боеголовки или гибнут все города,
   обмен затухает сам. При доктрине `doomsday` мир кончается за 2–3 волны.
5. `reset` возвращает арсеналы, гасит войны и отменяет запланированные ответы.

## 5. Тестирование

- **Юнит `diplomacy`**: `responseSize` — соразмерность обиде, кап по доктрине, половина для
  союзника (но не меньше 1), кламп по арсеналу, `off` → 0; `alliesOf` симметричны и не
  включают саму сторону/нейтральных.
- **Юнит sim**: удар США по России → через задержку ответ России по США, арсенал потрачен;
  доктрина `off` — ответа нет; союзник России вступает позже и меньшим залпом; несколько
  попаданий подряд дают ОДИН ответ; анонимный удар → жертва винит другую сторону, но не
  себя; нейтральные не отвечают; обезглавленная/безоружная сторона не отвечает; `reset`
  отменяет запланированный ответ и снимает войны; детерминизм от seed.
- **Дым headless**: залп США→Россия при доктрине `restrained` запускает цепочку ответов,
  в консоли нет ошибок; ленту и статусы войны видно в HUD.

## 6. Конфиг

`RETALIATION_DELAY_MIN/MAX = 3/6`, `ALLY_DELAY_EXTRA_MIN/MAX = 2/5` (сек),
`RETALIATION_PER_DEATHS = 6` (млн погибших на боеголовку ответа),
`RETALIATION_CAP_ESCALATE = 12`, `ALLY_RESPONSE_FRAC = 0.5`, `DEFAULT_DOCTRINE = 'restrained'`.
Кап 12 — ещё и защита пула ракет рендера (24 слота): волна не должна его выесть.

## 7. Что НЕ входит

Шкала отношений и переговоры, смена союзов по ходу партии, ПРО/перехват, первый удар по
решению ИИ (стороны только отвечают, сами войну не начинают), условия победы и экран итогов.

## 8. Риски

- **Лавина.** Цепочка ответов может поднять десятки ракет: капы волн + расход арсенала
  ограничивают, пул рендера деградирует мягко (graceful no-op, как и раньше).
- **Блоки союзников** — игровая условность для баланса, а не утверждение о реальных союзах;
  Индия и Пакистан намеренно оставлены без союзников.
- Обвинение случайной стороны при анонимном ударе — сознательная механика «песочницы»,
  отключается выбором своей стороны или доктриной `off`.
