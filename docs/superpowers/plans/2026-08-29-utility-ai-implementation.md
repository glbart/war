## Задачи (все выполнены 2026-08-29)

- [x] **1. `src/sim/ai/curves.ts`** — кривые отклика (poly/logistic/step) и свёртка оценки
      (произведение + компенсация схлопывания).
- [x] **2. `src/sim/ai/types.ts`** — `DecisionContext` (снимок знаний стороны), `RivalView`,
      действия, `Candidate`/`Decision` с разложением.
- [x] **3. `src/sim/ai/actions.ts`** — 8 шаблонов действий, их соображения, веса по нраву,
      фильтр доктрины, размеры волн.
- [x] **4. `src/sim/ai/decide.ts`** — перебор вариантов, оценка, порог, инерция, взвешенный
      жребий; выбранный вариант всегда первым в разложении.
- [x] **5. `Simulation`** — память обид с затуханием и погашением местью, пульс раздумий с
      разнесением по фазам, исполнение решений; удалены очередь ответов, `runRetaliations`,
      периодический перебор переговоров и автоответ ИИ на предложения.
- [x] **6. `sim/diplomacy.ts`** — убраны `responseSizeForLevel` и `peaceWillingness` (их роль
      забрали размеры действий и соображения); лестница, блоки и нравы остались как входы.
- [x] **7. Исход `pyrrhic`** — «разорённый мир»: война кончилась, но кто-то пал.
- [x] **8. HUD** — панель «почему» по клику на строку стороны, названия действий в ленте.
- [x] **9. Тесты** — `test/sim/ai.test.ts` (22: кривые, свёртка, таблица решений, размеры),
      обновлены `diplomacy`/`retaliation`/`salvo`/`warflow` под новую механику; всего 216.
- [x] **10. `scripts/balance.mjs`** (`npm run balance`) — массовые прогоны партий: исходы,
      длительность, потери, активность дипломатии.
- [x] **11. Версия 0.12.0**, банк памяти, спека и план.
