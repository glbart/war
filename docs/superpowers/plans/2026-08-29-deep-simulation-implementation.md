# Глубокая симуляция — план реализации

**Спека:** `docs/superpowers/specs/2026-08-29-deep-simulation-design.md`
**Ветка:** `claude/upcoming-features-status-rnx8r3`

## Задачи (все выполнены 2026-08-29)

- [x] **1. `src/sim/economy.ts`** — индексы экономик, доход, урон санкций (коалиционные вдвое),
      цена собственных санкций, восстановление с потолком от выжившего населения.
- [x] **2. `src/sim/espionage.ts`** — затухание осведомлённости, `effectiveKnowledge`,
      детерминированный шум показанного прогресса.
- [x] **3. `src/sim/un.ts`** — контекст голоса, поддержка по доказательствам и интересам,
      вето постоянных членов, подсчёт итога.
- [x] **4. `src/sim/sponsorship.ts`** — желание державы кормить чужую программу.
- [x] **5. `src/sim/scenarios.ts`** — три сценария партии (влияние, доктрина, заделы программ,
      стартовые кризисы, склонность к спонсорству).
- [x] **6. `Simulation`** — финансирование программ (спонсор ускоряет, безденежье тормозит),
      upkeep зонтиков и их срыв, разведка, резолюции с голосованием, спонсорские решения на
      пульсе, стартовый снимок кампании, сценарий как перезапуск партии.
- [x] **7. HUD** — экономика в статистике, второй ряд инструментов (разведка, зонтик, две
      резолюции), селект сценария, метки ☂/⛔⛔/⚑ и подсказка с осведомлённостью, строки ленты
      по всем новым событиям, расширенная сводка кампании.
- [x] **8. Тесты** — `deepsim` (18 юнитов) и восемь новых интеграционных в `campaign`;
      всего 266.
- [x] **9. `npm run balance`** — параметр сценария кампании; базовая линия бездействия
      проигрышна во всех трёх (fragile 255 с, cascade 152 с, coldwar 274 с).
- [x] **10. Версия 0.14.0**, банк памяти, спека и план. Отдельно написана спека плоской
      политической карты (`2026-08-29-flat-map-design.md`) — реализация следующим этапом.
