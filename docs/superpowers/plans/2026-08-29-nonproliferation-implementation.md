# Режим «Нераспространение» — план реализации

**Спека:** `docs/superpowers/specs/2026-08-29-nonproliferation-design.md`
**Ветка:** `claude/upcoming-features-status-rnx8r3`

## Задачи (все выполнены 2026-08-29)

- [x] **1. Страны-претенденты** — 8 новых фракций (Иран, Саудовская Аравия, Турция, Египет,
      Япония, Южная Корея, Бразилия, ЮАР) с городами, цветами, нравами и слабой ПРО;
      `ASPIRANTS` / `NUCLEAR_POWERS` в `sim/factions.ts`.
- [x] **2. `src/sim/proliferation.ts`** — стадии программы, профили (мотивация/потенциал),
      скорость, продвижение, подозрение и раскрытие, дрейф мотивации, согласие на договор,
      откаты от саботажа и удара. Чистый TS под vitest.
- [x] **3. Контракты** — команды `offerTreaty` / `imposeSanctions` / `inspect` / `sabotage`;
      события `campaignChanged`, `programRevealed`, `nuclearTest`, `treatyAnswer`,
      `sanctionsImposed`, `inspected`, `sabotageResult`; `gameOver` + сводка кампании.
- [x] **4. `Simulation`** — программы, влияние и часы партии, тик кампании, испытание с
      каскадом мотивации и выдачей арсенала, инструменты со списанием влияния, откат
      программы от удара и штраф влияния игроку.
- [x] **5. Исходы кампании** — `nonproliferation` / `proliferated` в `sim/victory.ts`,
      приоритетнее военных исходов.
- [x] **6. За сторону игрока больше не решает ИИ** (баг, найденный тестом переговоров).
- [x] **7. HUD** — влияние и часы партии, панель программ с выбором цели и полосами прогресса,
      четыре кнопки инструментов, строки ленты по кампании, кампания на экране итогов;
      претенденты попадают в список сторон только с бомбой или войной.
- [x] **8. Тесты** — `proliferation` (12), `campaign` (10), обновлены `factions`/`victory`/
      `warflow`; всего 240.
- [x] **9. `npm run balance`** — сценарии `idle` (базовая линия кампании) и `war`; базовая
      линия: бездействие = 100% поражение к ~276 с, 3 новые державы.
- [x] **10. Версия 0.13.0**, банк памяти, спека и план.
