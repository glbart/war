# Плоская политическая карта — план реализации

**Спека:** `docs/superpowers/specs/2026-08-29-flat-map-design.md` (с ревизией «реальные границы»)
**Ветка:** `claude/upcoming-features-status-rnx8r3`

## Задачи (все выполнены 2026-08-29)

- [x] **1. `scripts/gen-countries.mjs`** (`npm run gen:countries`) — скачивает Natural Earth
      Admin 0 1:110m, растеризует скан-лайном (чёт-нечет, дырки-анклавы бесплатно) в
      equirect 1024×512, сжимает RLE → `src/sim/countries.data.ts` (34 КБ base64, 177 стран).
      Фолбэк ISO_A3 → ADM0_A3: у Natural Earth Франция и Норвегия помечены `-99`.
- [x] **2. `src/sim/countries.ts`** — ленивое разжатие растра, `countryAt`, `countryNameAt`,
      таблица «ISO → сторона игры» и `factionAt`; спорные территории остаются нейтральными.
- [x] **3. `src/render/politicalMap.ts`** — чистая сборка RGBA-картинки: вода, заливка по
      сторонам, тёмные границы на стыках, подсветка выбранной стороны; проекции туда-обратно.
- [x] **4. `src/render/MapView.ts`** — своя сцена с ортокамерой, плоскость с текстурой,
      инстансированные маркеры городов, панорама/зум/пик, `factionAtScreen`.
- [x] **5. `Renderer.setViewOverride`** — режим карты подменяет сцену и камеру целиком, глобус
      и его эффекты не трогаются; `PointerController.enabled` гасит управление глобусом.
- [x] **6. `main.ts` + HUD** — кнопка «🗺 Плоская карта», клавиша M, ввод карты (драг, колесо,
      клик-удар, Shift+клик — выбор страны), синхронизация гибели городов, подсветка выбранной
      цели; dev-хук `__map` для headless-приёмки.
- [x] **7. Тесты** — `countries` (5) и `politicalMap` (7): растр, столицы в своих странах,
      привязка к сторонам, цвета, наличие границ, согласованность проекций; всего 278.
- [x] **8. Версия 0.15.0**, банк памяти, ревизия спеки.
