# systemPatterns — Архитектура и ключевые решения

## Главный шов: Command → Simulation → Events

```
Ввод/HUD ──► Command ──► SimHost ──► Simulation ──► Events ──► Renderer + HUD
                                        │                       (только чтение)
                                 авторитетное состояние
```

- **Ввод никогда не меняет состояние игры.** Клик и кнопки порождают `Command` (намерение).
- **Мутирует только `Simulation`.** Она потребляет команды на тике и выпускает `Events` (факты).
- **Рендер и UI — читатели.** Ни одна игровая величина не живёт в HUD: он рисует то, что пришло
  событием (`factionsChanged`, `campaignChanged`, `decisionMade`, …).

`SimHost` — интерфейс `post()` / `step()` / `drainEvents()`. Границы Web Worker и сети имеют ту
же форму, поэтому реализацию можно подменить, не трогая вызывающий код: сейчас `LocalSimHost`,
дальше — `WorkerSimHost`, потом сетевой. Симуляция (`src/sim`, `src/ecs`) **не импортирует ничего
из `render`/`ui`/`input`** и не трогает DOM: 2000+ строк логики гоняются headless.

**Для будущей сети выбран server-authoritative поток событий, а не lockstep**: в симуляции есть
`Math.sin/exp/pow`, побитовая воспроизводимость между движками не гарантируется, а авторитет
сервера снимает вопрос (детерминизм нужен только для реплеев и тестов, где движок один).

## Симуляция

- **Фиксированный тик 30 Гц**, всё через `dt`; никаких часов и `Math.random` внутри sim.
- **ECS (miniplex)** — только для эфемерных сущностей (боеголовки в полёте). Долгоживущее
  состояние (города, арсеналы, программы, отношения) живёт полями `Simulation`.
- **Правила — чистые модули**: `diplomacy`, `proliferation`, `economy`, `un`, `espionage`,
  `sponsorship`, `victory`, `ai/*`. Каждый тестируется таблицей, без запуска партии.
- **Контракты событий описывают ЗНАНИЕ, а не истину**: `ProgramView` отдаёт то, что игрок знает
  (стадия скрыта, прогресс с шумом) — так туман войны существует, а не рисуется.

## Слой принятия решений (Utility AI)

Поведение стран не написано ветками, а **вычисляется** (`sim/ai/`):

- **Соображение** = вход → нормализация 0..1 → кривая отклика (`curves.ts`, данные m/k/b/c).
- **Оценка варианта** = произведение соображений (любой ноль — вето) с компенсацией схлопывания
  из IAUS: `s + (1−s)·(1−1/n)·s`.
- **Вариант** = действие × цель (`wait · demonstrate · limited · massive · allOut · joinAlly ·
  proposePeace · acceptPeace`), веса — по нраву стороны, доктрина жёстко отсекает недоступное.
- **Выбор**: порог бездействия, инерция прошлому выбору, взвешенный жребий среди топ-полосы.
- **Пульс**: каждая сторона думает раз в `AI_PULSE_T`, стороны разнесены по фазам; **за сторону
  игрока ИИ не решает**.
- **Объяснимость**: `decide()` возвращает разложение (выбранный вариант первым), оно уходит
  событием `decisionMade` в панель «почему».

## Данные вместо кода

- **Запечённые геоданные**: `scripts/gen-landmask.mjs` (маска суши) и `scripts/gen-countries.mjs`
  (границы Natural Earth 1:110m → растр 1024×512, RLE, 34 КБ base64). В рантайме ни сети, ни
  зависимостей. После перегенерации — `npx prettier --write` на файл данных.
- **Таблицы**: фракции и их города, нравы, блоки союзников, ПРО, экономические индексы, профили
  программ, сценарии кампании, кривые соображений. Балансировка = правка чисел.
- **Все константы тюнинга — в `assets/config.ts`** (единственное место).

## Рендеринг

- `three/webgpu` с автооткатом на WebGL2 за интерфейсом `Renderer`; эффекты — на **TSL**
  (узловые материалы), один код на оба бэкенда.
- **Никакого динамического света** — устранённый источник лагов эталона.
- **Всё эфемерное — из пулов и инстансов**: ракеты, взрывы, декали, обломки, вспышки ПРО,
  маркеры городов. Движение считается в шейдере от `uTime` по пер-инстансным атрибутам —
  ноль работы CPU на кадр.
- **Поля-текстуры в equirect**: `DamageField` (кратеры/гарь), `HoleMask`, `WaterField`. Та же
  проекция, что у плоской карты, — наложения бесплатны.
- **Воксельная кора** (`crust/` + `CrustView`): удары выгрызают материал, Surface Nets мешит
  чанки, целостность падает, на нуле — раскол планеты.
- **Два вида**: `Renderer.setViewOverride` целиком подменяет сцену и камеру (глобус ↔ плоская
  карта), `PointerController.enabled` гасит управление глобусом. Карта — своя сцена с
  ортокамерой, текстура строится чистой функцией `politicalMap.buildPoliticalPixels`.

## Тестирование

- **Vitest** — чистая логика: гео, жертвы, кривые, решения (таблицей контекстов), программы,
  голосования, экономика, исходы, границы. Плюс интеграционные прогоны партий.
- **Общие помощники** `test/helpers/` (`war.ts`, `ai.ts`): прогон тиков, фильтры событий, сборка
  синтетических контекстов, поиск сида, на котором удар долетает (ПРО может сбить!).
- **Headless-приёмка** `scripts/accept/shots.mjs` — Chrome + swiftshader, ловит ошибки компиляции
  TSL-шейдеров, которых не видят сборка и юниты. Dev-хуки (`__strike`, `__hud`, `__map`) —
  только под `import.meta.env.DEV`.
- **Баланс — тоже проверка**: `npm run balance` гоняет партии пачками и печатает распределение
  исходов. Базовая линия: бездействие обязано проигрывать.

## Правила, проверенные болью

- Node-материалы three: непрозрачный материал не трогает `opacity` (исчезновение — масштабом);
  выходы цвета клампятся в ≥0 (отрицательные значения писать через `outputNode`); накопление
  в render-target — ping-pong `max`, а не blending (WebGL2-бэкенд не поддерживает MAX).
- Скрытие через атрибут `hidden` перебивается `display:flex` — возвращать явным CSS.
- Прилетевшая ракета может сорвать только что подписанное перемирие — это не баг, а драма.
