# Банк памяти проекта

> **ЯЗЫК ОБЩЕНИЯ — РУССКИЙ.** Всё общение с пользователем — на русском. Исключения только для
> технических терминов, названий библиотек, кода и команд. Правило действует во всех сессиях.

Проект живёт в `glbart/nuclear-strategy` (игра). Песочница-визуализация, из которой он
вырос, — отдельный репозиторий `glbart/war`; общего кода у них больше нет, только общая
история до 2026-08-30.

Этот каталог — источник истины по проекту. Он существует, потому что между сессиями память
обнуляется: чтобы продолжить работу, нужно прочитать эти файлы.

## Порядок чтения

1. **projectbrief.md** — что это за игра и зачем (корневой документ, задаёт цель).
2. **productContext.md** — петля игры, ощущения, условности.
3. **systemPatterns.md** — архитектура: главный шов, слои, Utility AI, данные, рендер, тесты.
4. **techContext.md** — стек, команды, внешние данные, ограничения.
5. **activeContext.md** — где мы сейчас и что дальше (**читать обязательно**).
6. **progress.md** — что работает по подсистемам + хронология версий + бэклог.

## Где лежит остальное

- `docs/superpowers/specs/` — спеки фич (по одной на фичу, с датой в имени).
- `docs/superpowers/plans/` — планы реализации к спекам, с отметками выполнения.
- `src/assets/changelog.ts` — пользовательский ченджлог (виден в игре в окне «Что нового»).

## Как обновлять

После значимой работы: `activeContext.md` (фокус и следующие шаги) и `progress.md` (что
заработало). Архитектурные решения — в `systemPatterns.md`, смена стека или данных — в
`techContext.md`. Крупная фича = спека + план + запись в оба живых файла.
