# activeContext — Где мы сейчас и что дальше

_Обновлено: 2026-08-30 · версия 0.15.0 · 278 юнит-тестов в 38 файлах · master = `f5b4623`_

## Состояние в одном абзаце

Проект перестал быть демо-песочницей: это играбельная симуляционная стратегия про
**нераспространение**. Игрок выбирает сторону (по умолчанию США) и сценарий, тратит
влияние на дипломатию, санкции, инспекции, зонтики, разведку, саботаж и резолюции ООН,
чтобы за `CAMPAIGN_T` = 600 с ни одна из восьми стран-претендентов не получила бомбу.
Ядерный удар доступен всегда — и почти всегда проигрышный ход. Мир смотрится на глобусе
или на плоской политической карте с реальными границами (клавиша **M**). Поведение
ИИ-стран считает Utility AI, каждое решение объяснимо в панели «почему».

## Что сделано последним

**Плоская политическая карта с реальными границами** (спека
`docs/superpowers/specs/2026-08-29-flat-map-design.md`, ревизия §2 — реальные границы вместо
Вороного по городам; план рядом):

- `npm run gen:countries` печёт Natural Earth Admin 0 1:110m (общественное достояние) в
  `src/sim/countries.data.ts`: растр equirect 1024×512, RLE, **34 КБ base64**, 177 стран.
  В рантайме ни сети, ни зависимостей. Грабли: у Франции, Норвегии и Косова
  `ISO_A3 = '-99'` → фолбэк на `ADM0_A3`.
- `sim/countries.ts` — ленивое разжатие, `countryAt` / `countryNameAt` / `factionAt`,
  явная таблица «ISO → сторона игры». Тайвань, Косово, Северный Кипр — нейтральны.
- `render/politicalMap.ts` (чистый TS) — вода, приглушённая заливка по сторонам, тёмные
  границы на стыках, подсветка выбранной страны, проекции туда-обратно.
- `render/MapView.ts` — своя сцена с ортокамерой, плоскость 2:1 с DataTexture,
  инстансированные маркеры городов, панорама/зум/`pick`/`factionAtScreen`.
- Переключение — `Renderer.setViewOverride` (сцена и камера подменяются целиком, глобус не
  трогается) + `PointerController.enabled`. Кнопка «🗺 Плоская карта» и клавиша **M**.
  Драг — панорама, колесо — зум, клик — удар, **Shift+клик — выбрать страну** как цель
  инструментов.
- Ограничение v1: военные эффекты (кратеры, следы ракет, вспышки ПРО) на карте не рисуются —
  они живут в сцене глобуса.

Проверки: 278 юнит-тестов, `tsc`, `build`, `lint` — чисто; headless: переключение видов,
зум/панорама, удар с карты, Shift+выбор Ирана — 0 ошибок консоли.

## Что дальше (порядок — предложение, не обязательство)

1. **Военные эффекты на плоской карте** — кратеры, следы ракет, вспышки ПРО как слои
   `politicalMap`/`MapView`. Сейчас долгая партия на карте «немая».
2. **События-кризисы как данные** — таблица MTTH (переворот, утечка технологий, авария на
   объекте, смена режима), условия и эффекты в `assets/`, обработка в `Simulation`.
3. **Внутренняя политика стран** — второй контур давления: правительство, оппозиция,
   легитимность; санкции бьют не только по индексу экономики.
4. **Вынос коры и раскола в sim** — сейчас это геймплейное состояние живёт в рендере
   (`render/shatterState.ts`, `crust/`), что мешает воркеру и сети.
5. **`WorkerSimHost`** — репетиция сетевой границы: та же форма `post/step/drainEvents`.
6. **Радиация и ядерная зима**, **сетевой слой**, **код-сплиттинг бандла**.

Полный бэклог и что уже работает по подсистемам — в `progress.md`.

## Что держать в голове, начиная работу

- **Общение с пользователем — на русском** (`CLAUDE.md`), включая отчёты и коммиты.
- Рабочий процесс: **спека → план → реализация с тестами → приёмка → банк памяти**.
  Спеки и планы — в `docs/superpowers/`, по одной паре на фичу, с датой в имени.
- Перед мёржем: `npm test`, `npm run build`, `npm run lint`; по возможности
  `npm run balance` (бездействие обязано проигрывать) и headless-прогон, если трогали рендер.
- Симуляция не импортирует `render`/`ui`/`input` — это правило важнее удобства.
- Все константы тюнинга — только в `src/assets/config.ts`.
- Крупная фича = запись в `changelog.ts` (мелкие фиксы туда НЕ пишем — решение пользователя).
