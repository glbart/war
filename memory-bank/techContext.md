# techContext — Стек, инструменты, запуск

## Стек

| Слой | Технология | Почему |
| --- | --- | --- |
| Сборка/дев-сервер | **Vite 8** | HMR, быстрый билд |
| Язык | **TypeScript 6** (strict) | типы критичны, когда клиент и сервер делят код |
| 3D | **three.js 0.185** (`three/webgpu`) | WebGPURenderer + откат на WebGL2, TSL-материалы |
| ECS | **miniplex 2** | эргономичный TS, компоненты-объекты, лёгкая сериализация |
| Тесты | **Vitest 4** | нативно к Vite; логика симуляции гоняется без GPU |
| Качество | **ESLint + Prettier** | единый стиль, ловля ошибок |
| Деплой | **GitHub Pages** (`.github/workflows/deploy.yml`) | пуш в `master` → тесты → сборка → публикация |

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | дев-сервер с HMR |
| `npm test` | юнит-тесты (≈280, без GPU) |
| `npm run build` | `tsc --noEmit` + прод-сборка |
| `npm run lint` | ESLint + проверка форматирования |
| `npm run balance` | массовые прогоны партий: `-- [партий] [доктрина] [лимит] [idle\|war] [сценарий]` |
| `npm run accept` | headless-приёмка рендера (нужен `CHROME_BIN`) |
| `npm run gen:landmask` | перепечь маску суши в `src/sim/landmask.data.ts` |
| `npm run gen:countries` | перепечь границы стран в `src/sim/countries.data.ts` |

После генераторов данных прогнать `npx prettier --write` на созданный файл.

## Внешние данные

- **Границы стран** — Natural Earth Admin 0 1:110m (общественное достояние), 177 стран.
  Скачиваются генератором, в репозиторий попадает растр 1024×512 в RLE (~34 КБ base64).
  В рантайме сети не требуется.
- **Маска суши** — запечена из Blue Marble (512×256 битсет).
- **Города** — ~266 крупнейших агломераций (название, координаты, население) прямо в коде
  (`sim/cities.ts`), офлайн.
- **Подписи и границы поверх глобуса** — тайловый слой Esri (единственная сетевая зависимость
  рантайма; без сети просто нет подписей). Плоская карта своих границ из сети НЕ тянет.
- **Карта рельефа** — `earth-topology.png` с unpkg, best-effort.

## Ограничения

- **WebGPU есть не везде** → обязателен автоматический откат на WebGL2; оба пути проверяются.
- **TSL-шейдеры компилируются в браузере**: сборка и юнит-тесты их не проверяют — только
  headless-приёмка (`npm run accept`) или ручной прогон.
- Целевая платформа — **десктопный браузер**. Мобильный (тач, pinch-zoom) вне скоупа.
- Прод-бандл — один чанк >500 КБ (three/webgpu): предупреждение `vite build`, не блокер;
  код-сплиттинг лежит в бэклоге.
